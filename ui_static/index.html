📖 Runner & Hosting Operations Guide

🚀 How to Start & Stop Hosting
Method 1: One-Click Windows Launchers (Easiest)
  • Start Hosting: Double-click start_ui.bat in the project folder. It frees port 5000, starts the server, and automatically opens your browser!
  • Stop Hosting: Double-click stop_ui.bat in the project folder, or click the red 🛑 Stop Hosting button on the top right bar.
Method 2: Command Line (PowerShell / Terminal)
python ui_server.py

To stop: Press Ctrl + C in that terminal window.
