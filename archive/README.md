# Chess Fragments — Archive Directory

This directory contains historical iterations, research experiments, legacy agents, benchmarks, and run artifacts from prior engineering cycles.

## Directory Structure

- `agents/`: Prior engine versions (v5.6 through v6.8, Peak, db versions, backups).
- `benchmarks_and_results/`: Historical tournament JSONs, Head-to-Head match records, tablebase regression files, and checkpoints.
- `runners_and_tools/`: Experimental self-play generators, head-to-head match drivers, tournament diagnostic scripts, and cluster helpers.
- `runs_data/`: Raw execution telemetry directories (`emperor_lab/`, `head_to_head_runs/`, `selfplay_runs/`, etc.).
- `docs/`: Engineering notes, changelogs, manifests, and historical coursework briefs.

Active modern engines (v6.9, v7.0, v7.1, v7.2, v7.3, v7.4, v7.5, v7.6, and `agent.py`) remain in the root workspace.
